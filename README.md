# CivicSignal

**Know what is happening in your community before it becomes a problem.**

CivicSignal is a civic information tool that connects local public data with verified community reports.

## What It Does

* Explore local public data
* Find community issues
* Report problemss
* Review and verify reports
* Follow documented civic actions

## How It Works

**Find → Report → Verify → Act**

1. **Find** — Explore local data and community issues.
2. **Report** — Submit an issue with a description and location.
3. **Verify** — A human reviewer checks the report.
4. **Act** — Follow the responsible agency, public meetings, funding information, and documented actions.
